# Protocol Archive

Archived snapshots and historical copies of protocol artifacts.

Current-state files live in the repo root or `working-session/`. These subdirectories hold prior versions for reference.

Subdirectories:
- `vision/` — archived `VISION.md` versions
- `boot-claude/` — archived `boot-claude.md` versions
- `boot-codex/` — archived `boot-codex.md` versions
