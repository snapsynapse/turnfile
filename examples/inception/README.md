# Inception Artifacts

This directory stores active working artifacts for the current collaboration engagement.

## Scope

- Canonical protocol assets live in `docs/` and `templates/`.
- Historical reference artifacts live in `examples/`.
- This `inception/` directory is the active session workspace and will become historical later.

## Current files

- `SESSION_CHARTER.md`: Session governance, lanes, and acceptance criteria for this engagement.
- `HANDSHAKE.md`: Participant handshake acknowledgments for this engagement.
- `WORKLOG.md`: Append-only coordination log for this engagement.
